百度网盘绑定

直接提交百度 OAuth 返回的 Access Token 凭证，由后端 BFF 统一接管

本页不再收集 client_id、client_secret、redirect_uri，只负责把百度 OAuth 已返回的 Access Token 凭证提交给后端。

如何获取凭证

  1. 按百度网盘 OAuth 文档完成授权流程，拿到百度 OAuth 服务器返回的 Access Token 凭证。
  2. 如果你拿到的是完整 JSON 响应，可整段粘贴到本页。
  3. 如果你只拿到了 access_token 字符串，也可以直接粘贴。
  4. 提交后由后端 BFF 保存或接管该凭证，用于后续网盘访问。
